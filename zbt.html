One-time setup for “Refresh everything”
  1. Open GitHub: new fine-grained token, name it anything and pick an expiry.
  2. Repository access: Only select repositories, then fantasy-home.
  3. Permissions, Repository permissions: Actions: Read and write. Nothing else. Click Generate token.
  4. Paste the token below. It is saved only in this browser (localStorage), never in the repo.
