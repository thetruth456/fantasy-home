Static fantasy home base (plain HTML/CSS/JS, no build, no external resources) at https://thetruth456.github.io/fantasy-home/ (repo thetruth456/fantasy-home); works offline and on GitHub Pages (`.nojekyll` included).
`index.html` is the tabbed home: each league tab (Best League, ZBT, Oopsilons, SpaceX FF) shows that league's Week 7 report immediately. Standalone pages: `best-league.html`, `zbt.html`, `oopsilons.html`, `spacex-ff.html`; shared `style.css`, `report-core.js`, favicon files.
Each league has its own data file (`best-league-report.js`, `zbt-report.js`, `oopsilons-report.js`, `spacex-report.js`, each setting `window.REPORTS.<key>` with STARTERS, BENCH and WAIVER rows) and `report-core.js` renders all of them; the report text (quick read, league setup, notes) lives in the HTML of the league page and its `index.html` panel.
To add a new week: copy the current league page to `weeks/<league>-week<N>.html` (use `../` for style, script and icon paths) to archive it, then replace that league's data file and report text.
Add the new week to the top of that league's snapshot list (the `weekline` paragraph) in the league page and in its `index.html` tab panel, newest first.
