One-time setup for “Refresh everything”
  1. Open GitHub: new fine-grained token, name it anything and pick an expiry.
  2. Repository access: Only select repositories, then fantasy-home.
  3. Permissions, Repository permissions: Actions: Read and write. Nothing else. Click Generate token.
  4. Paste the token below. It is saved only in this browser (localStorage), never in the repo.

    Waiver flex options

    Top keepers

    • Cost is this year's draft round minus 2, including the round a player was already kept in. It is never earlier than the 1st or later than the 9th. A player who was not in this year's draft (waiver or free agency) costs a 9th. A trade does not change the round; the table shows whoever holds him now.
    • A player kept in both of the previous two seasons is ineligible and is left off the ranking. That uses the keeper flags on this league's drafts. Names, when the history has them, are under the table.
    • Value is expected points per game above a replacement player, minus the typical value of a pick in that keep round. Expected points average this year's scoring (pulled toward that player's Sleeper projection) and the Sleeper points of the same FantasyPros rest-of-season rank. The round's value is the ADP neighborhood of its middle pick. Best League uses the half-PPR rest-of-season ranks and this league's scoring. A dash means that input was missing.
